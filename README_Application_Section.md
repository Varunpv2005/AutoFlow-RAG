## 📸 Application

### Document Workspace

![AutoFlow-RAG Workspace](docs/screenshots/workspace.png)

The workspace provides document upload, indexing status, document metadata,
conversation management, and source-backed AI responses.

### Grounded Retrieval

![Grounded Answer](docs/screenshots/grounded-answer.png)

Retrieved responses expose supporting document information, page references,
chunk details, and retrieval similarity scores.

### Workspace Analytics

![Workspace Analytics](docs/screenshots/analytics.png)

The analytics dashboard provides visibility into document allocation,
conversations, chunk statistics, index health, retrieval metrics, and
infrastructure status.
